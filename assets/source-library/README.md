# Biblioteca visual fuente

Estos archivos vienen del paquete documental complementario y se conservan como materia prima. No sustituyen automáticamente las 63 ranuras públicas del sitio.

Para insertar imágenes visibles, usa únicamente las rutas exactas de:

- `/assets/data/image-manifest.json`
- `/assets/data/source-library-manifest.json`

La biblioteca contiene logos, símbolo, imagen social y cuatro miniaturas musicales recuperadas. `lse6-og.png` ya alimenta automáticamente la tarjeta social `assets/images/system/lse6-org-og.jpg`; las demás piezas pueden copiarse o renombrarse hacia las ranuras públicas cuando decidas qué lugar ocupan.
